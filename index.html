Como os dados funcionam

Esta versão salva os clientes no armazenamento local do navegador (localStorage). Não há envio automático para a internet, sincronização entre computadores ou acesso multiusuário. Limpar os dados do navegador pode apagar os cadastros; por isso, mantenha backups.

Os arquivos CSV e os PDFs são processados no próprio navegador. A logo está incorporada neste arquivo. A geração de PDF/ZIP ainda carrega bibliotecas externas (CDN) e precisa de internet.
