Como os dados funcionam

Esta versão salva os clientes em um banco SQLite local, gerenciado pelo servidor Python. O histórico de laudos utiliza o armazenamento do navegador nesta etapa. Não há envio automático para a internet, sincronização entre computadores ou acesso multiusuário. Limpar os dados do navegador remove o histórico de laudos, mas não apaga os cadastros do SQLite; mantenha backups para preservar ambos.

Os arquivos CSV e os PDFs são processados no próprio navegador. A geração de PDF/ZIP utiliza bibliotecas carregadas por CDN e, portanto, precisa de conexão com a internet para carregar essas bibliotecas.
